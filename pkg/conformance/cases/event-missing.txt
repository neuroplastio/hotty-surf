A method that takes the event (Go's surfrun.Event) is given it only by
$event, at that parameter's place: called without it, or given anything
else there, $value and null too, it is a load error. A <bind>'s do,
which may not use $event, can't call it.
-- typed --
A host whose parameters are all dyn, as surflua's Lua functions' are,
has no parameter of the event's type.
-- form.surf --
<surface>
  <button @click="saw('go')">a</button>
  <button @click="saw($value, 'go')">b</button>
  <button @click="saw(null, 'go')">c</button>
  <list>
    <bind key="x" do="saw('k')"/>
  </list>
</surface>
-- load --
