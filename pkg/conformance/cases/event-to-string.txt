$event goes to a parameter of the event's type only (Go's surfrun.Event),
and $value, a string, to a string parameter (or a dyn one): given to
another, each is a load error at its $ that names the parameter.
-- typed --
A host whose parameters are all dyn, as surflua's Lua functions' are,
takes $event and $value at any parameter: it has none to refuse them.
-- form.surf --
<surface>
  <button @click="typed($event)">a</button>
  <button @click="add($value)">b</button>
</surface>
