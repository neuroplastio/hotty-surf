# 2026-11-07: source code in both renderers

Added `code` with `language="plain|go|surf"`, and the matching
`surfui.Code(source).Language(...)` builder. Its local lexer preserves
source and escapes it as text. Tabs use eight-column stops; CRLF and
CR become line breaks, blank lines retain their rows, and long lines
clip inside the card instead of painting over a neighbour.

The approved syntax tokens default to existing roles. Design's review
sets keyword/tag to accent, string to ok, number to warn, type to info,
comment to muted and other text to ink. The host uses the terminal's
mono face and row height on the existing card ground. Cells use the
same default roles. Templates reject an unknown language.

The first tokenizer regression failed on the missing lexer; the final
suite covers source preservation, incomplete literals/comments, Unicode
and tabs, escaping, both template modes, and host/cells goldens. The
cells fixture includes a number so its reviewed tone is visible.

cases against the existing baseline (368 known differences), and 696
legibility documents with no failures. After Design's final number-tone
change, the native suite and the focused gates passed again: 30 fidelity
cases with none over threshold, and 12 legibility documents with none
failing. No new Blitz baseline case comes from code. The combined tour
