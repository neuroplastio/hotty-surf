# 2026-11-07: checkbox

A checkbox is a button with checkbox semantics. The app owns its checked
state, as for Switch; clicks, Space and Enter run its handler. The host
uses the reviewed 14px square, field/input when off, accent/on-solid when
on, and the kit's check glyph. Cells draw `[ ]` and `[x]` with the
ordinary focus and disabled roles.

The missing constructor failed the initial regression. Native tests cover
keyboard and pointer toggles, disabled state, both template modes and
host/cells goldens. The full native suite passes after the cursor-rule
correction. The focused fidelity gate has 30 cases, four documented
Dense 1.6× edge differences, and no unrecorded failures. All 12 focused
legibility documents pass. See blitz-gaps for each new baseline case.

The combined tour branch repeats make check after integration.
