# The gate on hotty-blitz 0.8.0

The Makefile's renderer notes now name hotty-blitz v0.8.0 (22ee077), as
hottyterm 0.8 does. Supply `HOTTY_BLITZ`, `HOTTY` and `HOTTY_FONTS` from
the same release checkout if the machine's make.mk still pins an older
one. The checkout is used read-only.

The browser oracle now loads the renderer's bundled OpenMoji alongside
AdwaitaMono and IBM Plex Sans. The same fallback setup serves the
fidelity, legible, rows and look tools. All 30 glyph/column cases pass
with matching fonts; a representative comparison is 0.0 CSS px².

The complete aligned fidelity run took 338 s under CAP: 2400 cases,
420 over the threshold. Against the old baseline, make gate exited 2
with 69 changes. They were inspected and reconciled: 44 removed, 13
added, 12 scores updated. Every other score and the metric are retained.
The measured cases all reconcile with that baseline. The full check on
the last migration commit will render and judge them again.

[`blitz-gaps.md`](../knowledge/blitz-gaps.md#hotty-blitz-080-2026-11-15)
records each changed group and why: synthetic italic and old edge
failures improve, while known text, underline, focus-line and box-edge
gaps cross the threshold or move. No framework CSS changed to meet a
renderer difference.
